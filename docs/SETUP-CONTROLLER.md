# Setup Controller HTML

Folder:

`controller/`

Untuk test lokal, buka `index.html`.

Jika browser membatasi request dari `file://`, jalankan web server sederhana.

Contoh jika ada Python:

```bash
python -m http.server 8080
```

Lalu buka:

`http://localhost:8080/controller/`

Atau upload folder `controller` ke hosting statis seperti:
- GitHub Pages
- Netlify
- Vercel

## Penggunaan
1. Isi Apps Script URL
2. Isi Controller token
3. Klik `Load Devices`
4. Pilih worker/profile
5. Isi URL
6. Klik `Open URL`

Contoh URL:

`https://tiktok.com/@ihsanbaihaqi`
